Design Tradeoffs

  • Pro: Maximum separation of concerns — the auth gate is handled before users ever see the step controls.
  • Pro: The existing 4-column layout is completely untouched.
  • Con: Adds an extra mandatory click for every user on every modal open, even Nacional-default users who gain nothing from it.
  • Con: Once inside Steps 1–3, the current scope is hidden unless a persistent indicator (breadcrumb) is added — which partly re-creates Option A.
  • Con: Requires modal-internal view state machine and transition animations.
  • Possible mitigation: Remember the last-used scope and auto-advance, showing the breadcrumb to change. But this only helps on repeat visits.
