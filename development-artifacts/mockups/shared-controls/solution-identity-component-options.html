Option A

Compact semantic code

Use a count-first label like "3 targets at 17% + 2 costs + 4 includes" when target levels match. If target levels differ, drop the percent and use "3 targets + 2 costs + 4 includes."

Option B

Plain title plus chips

Use a readable title and rely on compact chips for what to protect, costs, and included areas.

Option C

Generic run label

Use "Solution A" or "Run 14" as the primary title, then put all meaning in chips. Useful for comparison, weaker for recognition.
