Hatch, mesh, and dot patterns distinguish overlapping layers when opacity and color alone are not enough.

Recommendation

Put pattern controls inside each expanded selected-layer row.

Keep the collapsed row quiet, but show a small active-pattern badge when a pattern is enabled. This makes hatching intentional, reversible, and scoped to one layer at a time.

  • Opt-in per layer prevents accidental global hatching.
  • The expanded row already contains appearance controls, so the mental model stays consistent.
  • Preview tiles support quick recognition for color-blind and overlap-heavy workflows.

Options considered

A global hatch toggle is fastest but too easy to over-apply. A hidden style popover is cleaner but less discoverable. The expanded-row control is the best fit because it is local, visible, and consistent with existing layer styling.
