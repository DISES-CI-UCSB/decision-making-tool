Quick read

Fifteen visual strategies

  • Option 1 keeps a small button but makes it optically tight.
  • Option 2 reads like a text link and has the least visual weight.
  • Option 3 uses a divider row to make the whole lower edge feel intentional.
  • Option 4 makes the caret an icon action next to Change.
  • Option 5 makes the whole card the disclosure target, reducing button clutter.
  • Options 6-10 test bottom-right placement with different weights: pill, link, underline, badge, and compact split button.
  • Options 11-15 rebalance the whole widget by changing the card grid, footer, and action hierarchy.

Recommendation

Start with Option 12 or Option 13.

Option 12 keeps all three jobs visible without adding a heavy footer. Option 13 is the clearest disclosure pattern if the breakdown should feel like a card-level action.
