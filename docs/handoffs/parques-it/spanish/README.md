# Entrega técnica a TI de Parques — Decision Making Tool

## Qué es este paquete y a quién está dirigido

Este es el paquete de entrega técnica de Decision Making Tool, preparado para el equipo de TI (GTIC) de Parques Nacionales Naturales de Colombia (PNNC). Documenta qué es actualmente el sistema, qué evidencia respalda cada afirmación y qué sigue siendo una brecha o una decisión pendiente que Parques debe tomar.

**Cada afirmación de esta entrega técnica está marcada con uno de cinco estados** (consulte la leyenda a continuación), de modo que quien la revise pueda distinguir de un vistazo qué puede darse por verificado, qué debe confirmar y qué aún debe producirse. Las mediciones del 7 de septiembre de 2026 están en [Pruebas de rendimiento, carga y saturación](./performance-testing.md).

## Leyenda de estados

Cada hallazgo, requisito y afirmación de este paquete de entrega técnica utiliza uno de los siguientes cinco estados:

| Estado                                             | Significado                                                                                                                                                                     |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ✅ **Verificado**                                  | Confirmado directamente mediante el código fuente, la configuración o una prueba efectivamente ejecutada cuyo resultado se cita.                                               |
| 🟡 **Se requiere confirmación del equipo**         | Interpretación probable que el equipo del proyecto debe validar antes de que pueda considerarse un hecho.                                                                       |
| 🟠 **Se requiere decisión de TI de Parques**       | Decisión de despliegue, seguridad, responsabilidad o política que solo puede tomar la organización receptora.                                                                   |
| ⚪ **Planificado, aún no ejecutado**               | Prueba, artefacto o documento que cuenta con un plan definido, pero que aún no existe.                                                                                           |
| 🔴 **Brecha — no se encontró evidencia**           | Solicitud de GTIC o de la lista de entregables de julio de 2026 para la cual no se encontró plan ni evidencia en ninguna parte del repositorio.                                  |

## Glosario

| Término       | Significado                                                                                                                                                                                          |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **GTIC**      | Grupo de Tecnologías de Información y Comunicaciones — la unidad de TI de PNNC que recibe esta entrega técnica.                                                                                      |
| **PNNC**      | Parques Nacionales Naturales de Colombia — la institución receptora.                                                                                                                                 |
| **SIRAP**     | Sistema Regional de Áreas Protegidas. Tres usos en esta herramienta: (1) AOI de límite en el mapa; (2) catálogo regional de soluciones; (3) región de acceso en Firebase. Solo Eje Cafetero y Orinoquía tienen datos de catálogo/acceso. |
| **RUNAP**     | Registro Único Nacional de Áreas Protegidas — registro nacional de áreas protegidas de Colombia.                                                                                                     |
| **OMEC**      | Otras Medidas Efectivas de Conservación Basadas en Áreas — categoría de área de conservación distinta de RUNAP.                                                                                     |
| **AOI**       | Área de interés (Area of Interest) — área geográfica que una persona usuaria selecciona o dibuja para consultar métricas de conservación.                                                           |
| **UAT**       | Pruebas de aceptación de usuario (User Acceptance Testing) — pruebas con guion y resultado aprobado/no aprobado frente a requisitos acordados, distintas de las pruebas de usabilidad.             |
| **ANS**       | Acuerdo de Nivel de Servicio (Service Level Agreement) — contrato de soporte y tiempos de respuesta solicitado por GTIC.                                                                            |
| **RTO / RPO** | Objetivo de Tiempo de Recuperación / Objetivo de Punto de Recuperación (Recovery Time Objective / Recovery Point Objective) — rapidez y grado de recuperación requeridos después de un incidente. |
| **COG**       | GeoTIFF optimizado para la nube (Cloud Optimized GeoTIFF) — formato ráster que permite lecturas parciales rápidas mediante HTTP.                                                                    |
| **WCAG**      | Pautas de Accesibilidad para el Contenido Web (Web Content Accessibility Guidelines) — estándar de accesibilidad citado en las pruebas de usabilidad.                                               |
| **SUS / SEQ** | Escala de Usabilidad del Sistema / Pregunta Única de Facilidad (System Usability Scale / Single Ease Question) — métricas estándar de pruebas de usabilidad.                                        |
